# 📘 TypeScript Practice Lab & Studies

Este repositório é o meu laboratório pessoal de estudos e práticas em **TypeScript**. Aqui você encontrará soluções para diversos desafios de lógica, exercícios práticos e pequenos projetos desenvolvidos ao longo da minha jornada de aprendizado (incluindo módulos da [Codecademy](https://www.codecademy.com)).

---

## 📂 Estrutura do Repositório

Para manter o código organizado, **cada projeto possui sua própria pasta** dentro do repositório. 

Dentro de cada diretório, você encontrará os arquivos com a implementação da lógica (`.ts`) e seus devidos dados ou utilitários.
