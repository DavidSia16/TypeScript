# 🛒 TypeMart — TypeScript Project

Este repositório contém a resolução do projeto **TypeMart**, desenvolvido durante o curso de TypeScript da [Codecademy](https://www.codecademy.com).

O objetivo principal deste projeto é aplicar conceitos de tipagem estática do TypeScript para gerenciar o fluxo de checkout de um e-commerce.

---

## 🎯 Funcionalidades

- **Busca de produtos:** Filtra o catálogo com base no nome informado.
- **Checagem de pré-venda:** Identifica e notifica se o produto requisitado está em pré-venda.
- **Cálculo de frete:** Define o frete como gratuito para compras acima de $25.
- **Cálculo de impostos e total:** Aplica alíquotas condicionais com base na localização de entrega (ex: New York) e calcula o valor final da compra.
- **Exibição do recibo:** Imprime no console um resumo completo do pedido formatado.

---

## 🛠️ Tecnologias Utilizadas

- **TypeScript** (Tipagem de variáveis, manipulação de tipos primitivos)
- **Node.js** (Execução do ambiente)
